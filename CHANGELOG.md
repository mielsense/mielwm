# Changelog

Notable changes to mielwm, newest first. Versions follow [semantic versioning](https://semver.org).

## 0.1.0

The first release.

- Workspaces 1 to 9 on one endless canvas, with tiles, stacks and floating windows, AeroSpace's default keys and gaps.
- An overview that zooms out to every window as a live picture, with search, a minimap and a curved lens.
- Three-finger swipes between workspaces, with a haptic click.
- A Settings window with a shortcut recorder, live appearance preview and Import from AeroSpace.
- Workspace numbers in the menu bar, and Barik support behind a switch.
- About 0.01% CPU and 89 MB of memory at rest.
